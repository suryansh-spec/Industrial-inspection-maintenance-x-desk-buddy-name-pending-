# Expanded visualization pack

Replace `visualize.py`, `test.py`, and `main.py` in your existing project with these versions.

Generated PNGs:
1. Dataset class distribution
2. Time-domain waveforms
3. FFT spectra
4. Welch power spectral density
5. Spectrograms
6. Statistical feature boxplots (RMS, standard deviation, peak-to-peak, kurtosis, skewness, crest factor)
7. Class-wise feature profile
8. Feature correlation
9. RMS vs kurtosis
10. Training curves
11. Learning-rate schedule
12. Confusion matrix
13. Normalized confusion matrix
14. Per-class precision/recall/F1 table
15. One-vs-rest ROC curves
16. Precision-recall curves
17. Prediction confidence histogram

The frequency plots assume 12 kHz sampling, matching the selected CWRU 12k drive-end data. Confirm the acquisition rate before applying these plots to a different sensor.
